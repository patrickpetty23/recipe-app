# MCP Configuration Checklist

Use this checklist before presentation to demonstrate AI infrastructure readiness.

## Local Setup

1. Confirm MCP/tool config file exists (`~/.codex/config.toml`).
2. Verify configured servers are reachable from your local environment.
3. Ensure no secrets are committed to repository.

## Demo-Ready Evidence

1. Show one MCP-assisted workflow step during development/demo.
2. Reference docs used by AI (`aiDocs/context.md`, `aiDocs/prd.md`, `aiDocs/roadmap.md`).
3. Show git commit history that reflects iterative sessions.
4. Keep a local verification artifact (`aiDocs/evidence/mcp-verification.md`).

## Pass Condition

- MCP tools respond successfully in your local dev setup.
- Team can explain how MCP improved build/debug speed.
