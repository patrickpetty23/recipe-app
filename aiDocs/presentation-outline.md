1. Problem statement
2. Why this problem matters
3. One-line value proposition

5. Founding hypothesis (`aiDocs/founding-hypothesis.md`)

1. Document-driven workflow (`PRD -> MVP -> roadmap -> implementation`)
2. Architecture walk-through (`aiDocs/architecture.md`)
3. Live flow:

   - OCR + parse (or AI meal identification)
   - edit
   - save
   - shopping checklist
4. Logging/debugging evidence (`aiDocs/debugging.md`)
5. CLI tests and fixture run (`scripts/run-cli-tests.ps1`)

1. What works now
2. Biggest risks remaining
3. Next iteration goals before final presentation
