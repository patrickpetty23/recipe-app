# Customer Interview Notes (Compiled)

## U1 Session

## Session Metadata

- Session ID: U1
- Date: February 25, 2026
- Participant profile: Roommate #1, undergrad student, cooks 4 nights/week, saves recipes from TikTok and YouTube
- Interviewer: Team member (Timur)

## Current Workflow (Before App)

- Builds lists in Apple Notes while switching between TikTok screenshots and YouTube descriptions.
- Pain points: repeated copy/paste between apps and missing one item during quick grocery trips.

## Observed App Session

- Time to complete flow: 1m 56s
- Number of ingredient corrections: 2
- Where they hesitated: fraction parsing confidence on "1/2 tbsp"; confirming one dropped line.

## Verbatim Feedback

1. "I would use this if it stays this fast."
2. "I like seeing what was dropped so I can sanity-check."
3. "I still read every ingredient once before trusting it."

## Actionable Product Changes

1. Keep dropped OCR line section visible by default.
2. Keep confidence values visible in editor.
3. Maintain one-tap add ingredient row at bottom.

## Priority

- Immediate before final presentation: confidence clarity + dropped-line transparency.
- Backlog: assistant suggestions for likely missing pantry staples.
