# 2x2 Differentiation Grid

## Axis Definition

- X-axis: **Input Flexibility** (single-source/manual -> mixed source capture/import)
- Y-axis: **List Automation Depth** (raw text capture -> structured editable shopping list)

## Grid

```text
High List Automation Depth
^
|                                  Recipe Scanner (this project)
|                                  - camera + screenshot input
|                                  - structured ingredient parsing
|                                  - editable shopping checklist
|
|                 Paprika / Mela
|                 - strong recipe organization
|                 - more manual setup for input
|
|       Google Lens / Live Text
|       - flexible capture
|       - weak recipe-specific list generation
|
| Manual Notes / Reminders
| - low automation
| - low setup, high manual effort
+-------------------------------------------------------------> High Input Flexibility
```

## Strategic Readout

1. Primary gap exploited: high input flexibility + high list automation in one flow.
2. Competitive pressure:
   - Generic OCR tools are close on capture flexibility.
   - Recipe managers are close on organization depth.
3. Differentiation depends on maintaining speed + edit reliability for messy real-world inputs.
